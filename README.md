# 🏨 Sistema de Restaurante Andino - Hotel Andino S.A.S.

## Descripción
Prototipo tecnológico desarrollado para el Hackathon del SENA que integra el control de inventarios, validación de derechos de alimentación de huéspedes y flujo de caja diario.

## Módulos del Sistema
- **Módulo de Huéspedes**: Registro y validación de planes de alimentación (1, 2 o 3 comidas diarias)
- **Módulo de Comandas**: Registro de pedidos con trazabilidad del mesero asignado y tipo de plato
- **Módulo de Inventario**: Sistema STOP - alerta automática cuando el stock es crítico
- **Módulo de Caja**: Reporte de ingresos del día diferenciando cortesías y cobros

## Seguridad
Sistema protegido con PIN de acceso para resguardar datos de huéspedes e información financiera.

## Tecnologías
- HTML5, CSS3 (Dark Mode / Glassmorphism)
- JavaScript (Vanilla JS)
- Base de Datos MySQL (hotel_andino_db.sql)

## Cómo ejecutar
1. Abrir index.html en el navegador
2. Ingresar PIN de acceso: **1234**
3. Navegar entre los módulos del sistema
